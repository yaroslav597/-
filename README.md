# АЭРО — наземная станция БПЛА

Локальный прототип React + Vite + Leaflet. Нужен Node.js 22 LTS и npm.

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Проверки: `npm test`, `npm run build`. Предпросмотр сборки: `npm run preview`.

Нажатие на карту добавляет точку; перетаскивание изменяет координаты. Выбор точки открывает форму координат и высоты. Точки сохраняются в localStorage. Доступны удаление, очистка, экспорт JSON, возврат домой и посадка в выбранном месте. Маршрут поддерживает до 100 точек.

Расстояние рассчитывается Turf.js по поверхности Земли, без учёта перепада высот. Время — расстояние / заданная скорость, без взлёта, посадки, ветра и остановок. Высоты 5–500 м — ограничения формы прототипа.

Телеметрия синтетическая, обновляется раз в секунду, не моделирует исполнение миссии. Команды аппарату не отправляются. Для карты и шрифта нужен интернет; при недоступности тайлов остаются точки и линии на пустой подложке, используется системный шрифт.

## Структура и следующий этап

- `src/domain/route.js`: расчёт расстояния и проверка путевых точек.
- `src/components/Map.jsx`: адаптер Leaflet.
- `src/services/telemetry.js`: demo-подписка и заготовка WebSocket-подписки с очисткой соединения.
- `docs/backend-contract.md`: предлагаемый контракт FastAPI / pymavlink / SITL.
- `tests/route.test.js`: проверки геодезии и валидации точек.

PDF не входит в исходники. Из вложения ВКР извлечён текст: этот этап реализует клиентское планирование; передача миссии по MAVLink, испытания SITL и оценка фактического трека относятся к следующему этапу.

## Точки, действия и завершение миссии

Все путевые точки соединены линией маршрута. Выберите точку, отредактируйте координаты и высоту, добавьте одно или несколько действий, расставьте их стрелками и нажмите «Сохранить точку». Можно менять скорость, поворачивать нос, зависать на время, указывать ROI, включать интервальную съёмку и делать одиночный снимок. Поле «Остановка после действий» задаёт дополнительную задержку. Для задержки перед снимком добавьте «Зависание на время» перед ним.

Взлёт и его высота задаются в настройках всей миссии. Завершение выбирается отдельно: возврат домой, посадка в указанном месте или удержание последней точки. Home обозначен H; место посадки — L. Укажите их нажатием на карту после нажатия соответствующей кнопки или перетащите маркер. Возврат к Home и подход к посадке входят в отображаемый путь и оценку расстояния. Home — плановый, а не полученный от автопилота; его нужно сверить с реальным Home перед загрузкой. Экспорт не меняет Home автопилота командой DO_SET_HOME.

ROI — отдельная цель наблюдения с собственными координатами и высотой. Её можно задать из редактора, выбрать на карте или переместить за маркер ◎. Тонкий золотистый пунктир показывает направление взгляда; целью перелёта ROI не становится. Точка, которой назначен ROI, остаётся в маршруте.

## Предпросмотр прохождения

«Запустить предпросмотр» показывает движение демонстрационного маркера, остановки и названия действий по порядку. Есть пауза, продолжение, сброс и ускорение ×1/×10/×50. Изменение сохранённой миссии сбрасывает предпросмотр. Учтены заданные скорости участков, ожидания, условный взлёт и посадка; кинематика упрощена, реальный автопилот не моделируется. Демо-телеметрия независима от этого предпросмотра.

## Хранение и экспорт

В localStorage хранится JSON версии 3: `waypoints=[{id,lat,lng,alt,delay,actions:[{id,command,params,target?}]}]` и `settings={speed,takeoff,takeoffAlt,ending,home,landing}`. Все настройки сохраняются при перезагрузке. Старые массивы точек автоматически преобразуются: DO/CONDITION и LOITER_TIME становятся действиями соответствующей точки; TAKEOFF и конечная команда переносятся в настройки. Координаты исходных точек сохраняются.

Экспорт дополнительно содержит `items`: `seq`, числовые `command` и `frame`, `param1`–`param4`, `x`, `y`, `z`, `current`, `autocontinue`. Русские названия используются только в интерфейсе. Для команд с координатами `x`/`y` — широта/долгота × 10⁷, `z` — высота относительно Home. У снимка `x=1` — значение параметра спуска затвора, а не координата.

Компиляция создаёт TAKEOFF при включённом взлёте, стартовую остановку и DO_CHANGE_SPEED, затем WAYPOINT для каждой точки, последовательности действий и завершающую RTL либо LAND. Для действий после прибытия добавляется служебный WAYPOINT в уже достигнутых координатах с запасом времени: минимум 3 секунды, для поворота — расчёт по полному обороту и заданной скорости (при нулевой скорости условно 10°/с). Группы действий разделяются LOITER_TIME там, где он задан пользователем. Дополнительная остановка после действий экспортируется как LOITER_TIME. Служебные точки не меняют геометрию маршрута. Из-за ограничений DO/CONDITION выполнение на реальном борту необходимо проверять в SITL: завершение NAV может прервать оставшиеся действия; реальная скорость поворота зависит от настроек борта. Предпросмотр показывает намерение пользователя и не доказывает выполнение команд автопилотом.

Справочник параметров: [ArduPilot Mission Commands](https://ardupilot.org/copter/docs/common-mavlink-mission-command-messages-mav_cmd.html). Передача MAVLink, подключение к автопилоту, ARM/START и SITL пока отсутствуют.
