# АЭРО — наземная станция БПЛА

Локальный прототип React + Vite + Leaflet. Нужен Node.js 22 LTS и npm.

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Проверки: `npm test`, `npm run build`. Предпросмотр сборки: `npm run preview`.

Нажатие на карту добавляет точку; перетаскивание изменяет координаты. Выбор точки открывает форму координат и высоты. Точки сохраняются в localStorage. Доступны удаление, очистка, экспорт JSON и замыкание маршрута. Лимит 100 точек ограничивает нагрузку синхронного оптимизатора.

Расстояние рассчитывается Turf.js по поверхности Земли, без учёта перепада высот. Время — расстояние / заданная скорость, без взлёта, посадки, ветра и остановок. Nearest neighbor + 2-opt сохраняет первую точку, работает с открытым и замкнутым маршрутом и не принимает результат хуже исходного. Это эвристика, глобальный оптимум не гарантируется. Высоты 5–500 м — ограничения формы прототипа.

Телеметрия синтетическая, обновляется раз в секунду, не моделирует исполнение миссии. Команды аппарату не отправляются. Для карты и шрифта нужен интернет; при недоступности тайлов остаются точки и линии на пустой подложке, используется системный шрифт.

## Структура и следующий этап

- `src/domain/route.js`: независимые расчёты и оптимизация.
- `src/components/Map.jsx`: адаптер Leaflet.
- `src/services/telemetry.js`: demo-подписка и заготовка WebSocket-подписки с очисткой соединения.
- `docs/backend-contract.md`: предлагаемый контракт FastAPI / pymavlink / SITL.
- `tests/route.test.js`: проверки геодезии и инвариантов оптимизации.
